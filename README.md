# AIを騙せ！（damashi-ai）v3

審判AIに「読める」と言わせつつ相手AIには間違えさせる、手書き数字バトルゲーム。
v3の目玉=**🔥リベンジモード「しんかAI」——騙すと、その場でブラウザ内の本物の機械学習（勾配降下）で特訓し、同じ技が二度と通じなくなる敵**。完全ブラウザ内動作（送信なし・依存ライブラリゼロ・サーバー不要）。

## 遊び方

`index.html` をブラウザで開くだけ（file://直開き対応）。スマホは指描き対応。v1（体験版）は `v1.html`。

- **🥊 たいせん Lv1/Lv2**: お題の数字を、審判AI（大型・99.0%）が読めて相手AI（小型）が誤答する形で描くと騙し成功。スコア=相手の誤答確信度×コンボ倍率。0〜9コンプで図鑑バッジ
- **🔥 リベンジ（しんかAI）**: Lv2ベースの学習する敵。騙すと特訓画面（ライブ損失曲線・確信度メーター）→同じ絵を再判定→看破される。特訓回数に応じ得点倍率UP（最大×3）。学習済み重みはlocalStorage永続=**あなたの騙し技だけを喰って育つ、世界に一体の敵**。図鑑から初期化可
- **⏱ 60秒ラッシュ**: 時間内に何回騙せるか
- **🔬 けんきゅうしつ**: 特徴マップ・判断根拠ヒートマップの観察
- **🧪 研究データ書き出し**（図鑑内）: プレイログ（手描き画像+判定）を自分の端末へJSONダウンロード。送信は一切なし

## 学習機構（v3の心臓）

- conv層凍結・全結合ヘッド（hidden64+fc10・約5.2万param）のみを純JSでSGD学習（クロスエントロピー）
- 忘却防止: クリーンMNIST特徴300本のリプレイバッファ同梱＋復習ステップ＋**元重みへのL2アンカー**（長期漂流を有界化）＋過去の騙し技12件を混ぜて再学習
- 早期終了（確信95%到達で打ち切り）→1回の特訓は実測**53ms**（演出でわざと2秒に伸ばしている）
- **仕様上の見どころ**: 特訓するとクリーン精度が98.5%→96%台に下がることがある=実在するML現象「頑健性と精度のトレードオフ」。ゲーム内では「AI学力テスト」として可視化し、**学習させて隙を作る**（データポイズニング）まで戦略になる
